Formalized in Lean 4 for numerical semigroups minimally generated by four elements. This public-source release presents five verified theorem interfaces: NS-SHARP, original P2/P3-STRONG, finite intrinsic equality classification, and finite ALL-PIVOTS.

## Exact formal scope

The corpus concerns numerical semigroups minimally generated by four elements. It contains exactly five public theorem interfaces: NS-SHARP, original P2-STRONG, original P3-STRONG, R75 finite intrinsic equality iff on the original Gamma and multiplicity base M, and finite ALL-PIVOTS on all four original pivots. The exact typed applications are in [PublicExactTargets.lean](PublicExactTargets.lean); theorem names, hypotheses and proof routes are in [PROOF_INDEX.md](PROOF_INDEX.md).

R80 actually rebuilt this unchanged proof corpus on a distinct, fresh Ubuntu cloud VM with Lean 4.34.0-rc1 and the nine fixed dependency revisions. It completed 2517 Lake jobs, checked the five exact interfaces, passed five individual standard-only axiom audits and eight genuine type-mismatch negative controls. Commander accepted that external execution with exact scope on 2026-10-19. Commander audited sources and provider execution evidence; Commander did not perform a second local Lean build. Mathlib dependency OLEAN cache was used on the new VM; no NS25Lean project OLEAN was imported.

The finite intrinsic equality and finite ALL-PIVOTS results are Lean-kernel-proved. They do not formalize historical NEIT/NEIT*, interior-edge/opposite-vertex classification or six-case geometric PCR. The old generic Scarf, MonomialNEITBridge and TopSocleBridge routes remain outside the certified public claim set. No human peer review or journal endorsement is asserted.

There are 391 frozen nonroot proof modules and one four-import production root. The root imports only BasePivotSharp, P2StrongOriginalR50, P3StrongAssemblyR68 and ECFiniteAllPivotsR75. The three Public*.lean verification files and 13 individual checks are outside production imports. The v1.0.0 publication packaging edits prose and adds citation metadata only; it does not change any Lean statement, proof, source header, import, or pinned dependency configuration.

## Reproduce

Use the exact checked-in lean-toolchain, lakefile.toml and lake-manifest.json. In a fresh copy without project .lake/build:

```sh
lake exe cache get
lake build NS25Lean
lake env lean PublicExactTargets.lean
lake env lean PublicAxioms.lean
lake env lean PublicCertificateAudit.lean
```

Do not run lake update. The dependency cache is permitted; NS25Lean object reuse is not a cold build. The five checks/axioms drivers must succeed and print only propext, Classical.choice and Quot.sound. Each checks/negative driver must fail with an actual Type mismatch rather than missing imports. See [BUILD_REPRODUCTION.md](BUILD_REPRODUCTION.md).
