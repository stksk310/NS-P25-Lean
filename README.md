# NS25Lean — sharp type bounds and finite equality classification

Lean 4 proofs for numerical semigroups minimally generated by four elements. **v1.1.0** aligns the formalization with the reorganized 109-page manuscript: common source-fiber, monomial strictness, return/compensation and equality proofs replace duplicated routes while preserving the original conclusions and all-original-pivots interface.

## Theorems and proof routes

The unchanged [PublicExactTargets.lean](PublicExactTargets.lean) applies NS-SHARP, original P2/P3-STRONG, finite intrinsic equality and finite ALL-PIVOTS. [PROOF_INDEX.md](PROOF_INDEX.md) lists their hypotheses and the new shared APIs. `NS25Lean.lean` retains its original four imports and adds `NS25Lean.ManuscriptAlignment`, which exports the common proof modules.

P2 B uses a uniform two-lane return argument. P2 C's positive and pure-pair cases construct the actual critical-predecessor inputs to a common compensation theorem. The existential equality certificate is independent of the P2/P3 strong final modules; the all-pivots classification uses their discharge. The generic floor APIs include zero-floor and endpoint cases.

The [27-family/246-operation matrix](verification/ALIGNMENT_SCOPE.md) states the exact alignment scope. Inherited H1 pure/mixed strong EXHAUST and endpoint statements remain outside the formalized scope. Historical geometric NEIT/NEIT* and six-case PCR are not claimed kernel-proven. No whole-paper certification or journal endorsement is asserted.

## Reproduce

Use the checked-in toolchain, lakefile and manifest. The public version is 1.1.0; the frozen internal Lake package version remains 0.1.0. Do not run `lake update`.

```sh
lake exe cache get
lake build NS25Lean
lake env lean PublicExactTargets.lean
lake env lean PublicAxioms.lean
lake env lean PublicCertificateAudit.lean
```

See [BUILD_REPRODUCTION.md](BUILD_REPRODUCTION.md) for all-source checks and the exact distinction between executed evidence and reproduction instructions.
